# Disk Cleanup — освобождение места на дисках

Универсальная инструкция для расчистки дисков на любом Windows-компьютере.
Скрипты лежат рядом в этой же папке (`tools/disk-cleanup/`).

---

## Общий план

### Фаза 1: Разведка — понять, что занимает место

1. **Общая картина** — сколько занято/свободно на каждом диске
2. **Top-каталоги** — какие папки верхнего уровня самые тяжелые
3. **Большие файлы** — файлы > 500 MB (настраиваемый порог)
4. **Старые файлы** — не открывались более N месяцев
5. **Медиа и архивы** — видео, ISO, торренты, игровые дистрибутивы

### Фаза 2: Решения — что удалить, что перенести

6. Просмотреть отчеты, принять решения по каждой категории
7. Удалить ненужное
8. Перенести с C: на другой диск то, что можно (см. раздел ниже)

### Фаза 3: Системная очистка диска C:

9. Стандартная очистка Windows (temp, кэши, логи)
10. Перенос тяжелых папок с C: на другой диск

## Фаза 1: Разведка

### Шаг 1.1 — Общая картина дисков

```powershell
# Запустить из папки со скриптами:
.\disk-overview.ps1
```

Показывает: диск, общий размер, занято, свободно, % использования.

### Шаг 1.2 — Top-каталоги по размеру

```powershell
# Для диска H:\
.\dir-sizes.ps1 -Path H:\ -Depth 1

# Для диска C:\
.\dir-sizes.ps1 -Path C:\ -Depth 1

# Глубже в конкретную папку:
.\dir-sizes.ps1 -Path "H:\Games" -Depth 2
```

Показывает каталоги, отсортированные по размеру. Пропускает недоступные папки (Access Denied).

### Шаг 1.3 — Большие файлы

```powershell
# Файлы > 500MB на диске H:\
.\large-files.ps1 -Path H:\ -MinSizeMB 500

# Файлы > 1GB на диске C:\
.\large-files.ps1 -Path C:\ -MinSizeMB 1024

# Результат сохраняется в CSV для удобного просмотра
```

### Шаг 1.4 — Старые файлы (давно не использовались)

```powershell
# Файлы > 100MB, не открывавшиеся больше 12 месяцев
.\old-files.ps1 -Path H:\ -MonthsOld 12 -MinSizeMB 100
```

### Шаг 1.5 — Медиа, архивы, дистрибутивы

```powershell
# Найти видео, ISO, архивы, торренты
.\find-media.ps1 -Path H:\
```

Ищет по расширениям:
- **Видео:** .mkv, .avi, .mp4, .mov, .wmv, .flv, .ts
- **ISO/образы:** .iso, .img, .vhd, .vhdx
- **Архивы:** .zip, .rar, .7z, .tar, .gz, .bz2
- **Торренты:** .torrent
- **Инсталляторы:** .msi, .exe (> 100MB)

## Фаза 2: Решения

После запуска скриптов — просматриваем отчеты и решаем по каждому файлу/папке:
- **DELETE** — удалить
- **MOVE** — перенести на другой диск
- **KEEP** — оставить

## Фаза 3: Системная очистка C:\

### Что обычно можно безопасно удалить на C:\

| Что                                  | Где                                          | Команда/действие                           |
|---------------------------------------|----------------------------------------------|--------------------------------------------|
| Временные файлы Windows              | `C:\Windows\Temp`, `%TEMP%`                  | `cleanmgr` или скрипт                     |
| Кэш обновлений Windows              | `C:\Windows\SoftwareDistribution\Download`   | Остановить wuauserv, удалить, запустить    |
| Старые версии Windows                | `C:\Windows.old`                             | `cleanmgr` -> "Previous Windows"           |
| Кэш браузеров                       | AppData\Local\{Chrome,Edge,Firefox}\Cache     | Через настройки браузера                   |
| Кэш npm/pip/nuget                   | `%APPDATA%\npm-cache`, `%LOCALAPPDATA%\pip`  | `npm cache clean --force`, `pip cache purge`|
| Docker images/volumes               | WSL/Docker Desktop                            | `docker system prune -a`                   |
| Recycle Bin                          | Корзина                                       | Очистить корзину                           |
| NVIDIA/AMD кэш шейдеров             | `%LOCALAPPDATA%\NVIDIA\DXCache`              | Удалить папку                              |
| Crash dumps                         | `C:\Windows\Minidump`, `%LOCALAPPDATA%\CrashDumps` | Удалить                             |
| Логи                                | `C:\Windows\Logs`                            | Выборочно удалить старые                   |

### Что можно перенести с C: на другой диск

| Что                        | Откуда (C:)                     | Как перенести                                              |
|-----------------------------|----------------------------------|------------------------------------------------------------|
| Пользовательские папки     | Documents, Downloads, Videos...  | ПКМ -> Properties -> Location -> Move                      |
| Игры (Steam)               | `C:\Program Files\Steam`        | Steam -> Settings -> Storage -> Move                       |
| Игры (Epic, GOG и др.)     | `C:\Program Files\...`          | Через настройки лаунчера                                   |
| WSL дистрибутивы           | `%LOCALAPPDATA%\Packages\...`   | `wsl --export` / `wsl --import` на другой диск             |
| Docker data                | WSL vhdx                         | Переместить WSL data disk                                  |
| Dev-репозитории            | `C:\dev`, `C:\Users\...\source` | Перенести папку, обновить пути в IDE                       |
| Node modules (глобальные)  | `%APPDATA%\npm`                 | `npm config set prefix D:\npm-global`                      |
| Виртуальные машины         | По умолчанию в Users             | В Hyper-V/VirtualBox задать другую папку                   |

## Скрипты

Все скрипты в папке `tools/disk-cleanup/`:

| Скрипт            | Назначение                                |
|--------------------|-------------------------------------------|
| `disk-overview.ps1`| Общая картина всех дисков                 |
| `dir-sizes.ps1`   | Размеры каталогов с сортировкой           |
| `large-files.ps1` | Поиск больших файлов                      |
| `old-files.ps1`   | Поиск старых больших файлов               |
| `find-media.ps1`  | Поиск медиа, архивов, дистрибутивов       |
| `cleanup-temp.ps1`| Очистка временных файлов на C:\           |

Все скрипты:
- Корректно обрабатывают Access Denied (пропускают недоступные папки)
- Выводят результат в консоль и сохраняют в CSV (`reports/` рядом со скриптами)
- Принимают параметры (пути, пороги, глубину)
- Ничего не удаляют автоматически — только отчеты
