# disk-cleanup

Набор PowerShell-скриптов для анализа и расчистки места на дисках Windows.
Ничего не удаляют без явного запроса (кроме `cleanup-temp.ps1 -Clean`, см. ниже) — по умолчанию
только показывают отчёт и сохраняют его в `reports/*.csv`.

Пошаговый план работы (разведка → решения → системная очистка C:) — в [`hdd-space.md`](hdd-space.md).
Здесь — краткая справка по каждому скрипту.

## Скрипты

Запускать из этой папки (`.\script.ps1 ...`).

| Скрипт | Что делает | Пример |
|---|---|---|
| `disk-overview.ps1` | Общая картина по всем дискам: занято/свободно/% | `.\disk-overview.ps1` |
| `dir-sizes.ps1` | Размеры каталогов верхнего уровня, отсортированные по размеру | `.\dir-sizes.ps1 -Path H:\ -Depth 1` |
| `large-files.ps1` | Поиск файлов больше порога | `.\large-files.ps1 -Path H:\ -MinSizeMB 500` |
| `old-files.ps1` | Большие файлы, давно не открывавшиеся | `.\old-files.ps1 -Path H:\ -MonthsOld 12 -MinSizeMB 100` |
| `find-media.ps1` | Видео/ISO/архивы/торренты/крупные инсталляторы | `.\find-media.ps1 -Path H:\` |
| `cleanup-temp.ps1` | Анализ (и по флагу — очистка) temp/кэшей на `C:\` | `.\cleanup-temp.ps1` (dry run), `.\cleanup-temp.ps1 -Clean` (удаляет) |

Общее для всех скриптов:
- Пропускают папки без доступа (Access Denied), не падают
- Параметры — путь, пороги по размеру/возрасту, глубина
- Результат — таблица в консоли + CSV в `reports/`

## Быстрый старт

```powershell
# 1. Общая картина по дискам
.\disk-overview.ps1

# 2. Самые тяжёлые папки на диске
.\dir-sizes.ps1 -Path H:\ -Depth 1

# 3. Большие файлы (> 500 MB)
.\large-files.ps1 -Path H:\ -MinSizeMB 500

# 4. Старые большие файлы (не открывались > 12 месяцев)
.\old-files.ps1 -Path H:\ -MonthsOld 12 -MinSizeMB 100

# 5. Медиа/архивы/дистрибутивы
.\find-media.ps1 -Path H:\

# 6. Temp и кэши на C:\ — сначала отчёт, потом (если нужно) очистка
.\cleanup-temp.ps1
.\cleanup-temp.ps1 -Clean
```

Дальше — смотреть CSV-отчёты в `reports/` и вручную решать, что удалить/перенести
(подробности и таблицы "что можно безопасно удалить/перенести" — в [`hdd-space.md`](hdd-space.md)).

⚠️ `cleanup-temp.ps1 -Clean` реально удаляет файлы (temp, кэши, prefetch и т.д., кроме Recycle Bin/`Windows.old`/Update-кэша — их через `cleanmgr /d C`). Остальные скрипты только читают диск и ничего не удаляют.
